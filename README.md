### Most Used Commands for Nest.js

1. **Create a New Nest.js Project**
```
npx @nestjs/cli new <project-name>
```

2. **Run the Development Server**
```
npm run start:dev
```

3. **Generate a New Module**
```
npx nest generate module <module-name>
# or shorthand
npx nest g mo <module-name>
```

4. **Generate a New Controller**
```
npx nest generate controller <controller-name>
# or shorthand
npx nest g co <controller-name>
```

5. **Generate a New Service**
```
npx nest generate service <service-name>
# or shorthand
npx nest g s <service-name>
```

6. **Generate a New Provider**
```
npx nest generate provider <provider-name>
# or shorthand
npx nest g pr <provider-name>
```

7. **Generate a New Middleware**
```
npx nest generate middleware <middleware-name>
# or shorthand
npx nest g mi <middleware-name>
```

8. **Generate a New Guard**
```
npx nest generate guard <guard-name>
# or shorthand
npx nest g gu <guard-name>
```

9. **Generate a New Interceptor**
```
npx nest generate interceptor <interceptor-name>
# or shorthand
npx nest g in <interceptor-name>
```

10. **Generate a New Pipe**
```
npx nest generate pipe <pipe-name>
# or shorthand
npx nest g pi <pipe-name>
```

11. **Add a New Library**
```
npx nest generate library <library-name>
# or shorthand
npx nest g lib <library-name>
```

12. **Build the Project**
```
npm run build
```

13. **Run Unit Tests**
```
npm run test
```

14. **Run End-to-End Tests**
```
npm run test:e2e
```

15. **Run a Specific Test File**
```
npm run test -- <file-name>
```

16. **Check Project Linting**
```
npm run lint
```

17. **Format Code**
```
npm run format
```

18. **Add a New Dependency**
```
npm install <package-name>
```

19. **Start Production Server**
```
npm run start:prod
```

20. **List All Available Commands**
```
npx nest --help
